## 📖 About The Project

**Balaji Chilukur Family Dhaba** is a modern, responsive web portal designed to showcase the authentic culinary heritage of pure vegetarian dining. Featuring a digital menu experience, rich photo showcases, location details for Moinabad and Pragathi Nagar, and intuitive navigation built for mobile and desktop diners.

---

## ✨ Features

- 🍲 **Pure Vegetarian Showcase:** Highlights authentic North Indian curries, tandoori specialties, and fragrant biryanis.
- 📱 **Mobile-First Responsive Layout:** Fluid navigation designed for quick ordering and menu browsing on smartphones.
- ⚡ **Zero-Dependency Lightweight Performance:** Built with clean semantic HTML5, modern CSS3 with custom variables, and vanilla JavaScript for sub-second load times.
- 🧭 **Dual Location Access:** Information, operating hours (11:00 AM – 11:00 PM), and contact info for both Moinabad and Pragathi Nagar branches.

---

## 🛠️ Technology Stack

- **Markup:** Semantic HTML5 with accessibility attributes (`aria-label`, `fetchpriority`, skip links)
- **Styling:** CSS3 (CSS Variables, Flexbox, Grid, Media Queries)
- **Scripting:** Vanilla JavaScript (ES6+)
- **Assets:** Web-optimized SVG icons and lightweight photography
